# ✈️ Travel Planner

Modern fullstack travel planning web application.

Users can choose a city, explore hotels, restaurants and museums, and build their own travel plan.

---

## 🚀 Tech Stack

### Frontend
- Vue 3
- Vite
- CSS / UI Design

### Backend
- Laravel 12
- REST API

### Database
- MySQL

---

## ✨ Features

✅ Choose city  
✅ Dynamic places list  
✅ Hotels / Restaurants / Museums  
✅ Add places to personal plan  
✅ Save travel plan to database  
✅ Modern dark UI
